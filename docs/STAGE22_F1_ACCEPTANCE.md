# Этап 2.2-F1 — Telegram и пользовательские действия

Новый путь включается `STAGE22_MARKET_TELEGRAM=1`. По умолчанию он выключен: команды бота по-прежнему ставят job v1 и не читают очередь E.

Каталог, российский снимок и сохранённый FX берутся из `THAI_CATALOG_ROOT`, `RUSSIAN_MARKET_ROOT` и `FX_OBSERVATION_PATH`, если вызов их не передал. ЦБ и магазины при этом не запрашиваются. Sender берётся из настроек Telegram только как объект отправки; тесты подставляют FakeSender.

Просмотр готового результата форматирует сохранённые карточки и не ставит новое событие. «Обновить Таиланд» ставит событие `personal` и не вызывает collect. Callback получает ответ сразу, проверка администратора остаётся. BUY-кандидат ставит одно событие E с устойчивым id отпечатка; российский текст сигнала не дублируется. Повтор события и повтор доставки новый сбор не начинают. Уже подтверждённые части сообщений при частичной отправке не отправляются снова.

## Пример из результата D

Тестовый каталог: ASUS ROG Strix SKU-MATCH17, `https://example.test/th-z-match`, jib, 80 000 ฿. Российская цена той же подтверждённой пары 250 000 ₽, курс 2.5, известных расходов 0. D считает `250000 − 80000 × 2.5 = 50000` ₽, 20%. Неизвестные расходы в сумму не входят.

```
Россия ↔ Таиланд
ASUS ROG Strix SKU-MATCH17
Подтверждено: та же конфигурация и полный артикул.
Магазин TH: jib
Наличие TH: в наличии
Цена TH: 80000 ฿ (200000.0 ₽)
Цена RU: 250000 ₽
Ссылка TH: https://example.test/th-z-match
Разрешение: 2560x1600
Цена TH проверена: 2026-10-14T10:00:00+00:00
Наличие TH проверено: 2026-10-14T10:00:00+00:00
Цена RU проверена: 2026-10-14T11:00:00+00:00
Наличие RU проверено: 2026-10-14T11:00:00+00:00
Неизвестные расходы не равны нулю: customs, delivery, exchange_spread, travel
Курс: 2.5 ₽ за 1 ฿, CBR, получен 2026-10-14T12:00:00+00:00.

Подтверждённая разница: Таиланд дешевле России, 50000.0 ₽, 20.0%, заметное преимущество
```

Кнопка у последней части: `Обновить Таиланд` / `ctrl:ptop_go`.

## Linux

Docker, `python:3.12-slim-bookworm`, Python 3.12.14, `--network none`, без production `.env` и рабочих томов. Расписание 08:00 Europe/Moscow не переносилось на сервер. Серверная приёмка и выпуск в этот пакет не входят.

Пустой сохранённый результат отвечает каждому получателю: «По сохранённому результату показывать нечего. Каталог пуст или подходящих предложений нет.» Без допустимого получателя запрос с пустым chat_id не отправляется и доставка не отмечается успешной. Просмотр из меню читает время непосредственно перед каждой частью и не создаёт событие. Свежий Thai TOP без пары говорит, что данные остаются информационными. Partial и 429 берутся из сохранённого coverage, например `advice: 429`.

Подтверждённая часть записывается на диск до следующей отправки. Авария между успешным HTTP и этой записью по-прежнему может повторить одну часть; это окно не считается закрытым.
